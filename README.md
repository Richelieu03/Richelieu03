## 🚀 Projects

### 🔮 [Ashley's Tarot](https://ashleystarot.netlify.app): AI Tarot Reading Web App
Full-stack bilingual (EN / 中文) app that generates personalised tarot readings with an LLM.
- **Stack:** Next.js, TypeScript, Supabase (Auth + Postgres), Google Gemini, deployed via Netlify CI/CD
- Server-side auth and per-user daily quotas on the AI endpoint to prevent API abuse
- Pre-written meanings for all 78 cards (upright / reversed) so guests get instant results with zero API cost
- Single-card daily draw and three-card spread, with reading history synced to the cloud

### 💡 [needyLamp](https://github.com/Richelieu03/needyLamp): A Lamp That Only Works When You Look At It
Team project (3 people), **lead contributor**: a desk lamp that lights up only when you're looking at it, with an idle "personality" (looks around, peeks, dozes).
- **Stack:** Python, OpenCV face tracking, Arduino, servo motors
- Led development as the top contributor, owning the lamp module and its integration with face tracking
- Built the **hardware**: Arduino-driven servo head that physically turns toward the user

### 🫀 Wireless Animal ECG Monitoring System 🏆 *National First Prize & Patent*
Real-time wireless ECG acquisition and visualisation for animals.
- Implemented BLE communication and high-frequency signal processing in **C# / WinForms**
- Real-time medical data visualisation for clinical use
